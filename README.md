# BigBasket Category Performance Diagnostic

## 1. Project Overview
End-to-end diagnostic pipeline combining SQL data extraction, spreadsheet cross-checks, Tableau visualization, and Python cleaning to audit category target variance.

## 2. Tableau Public Dashboard
* **Live Dashboard URL:** [Tableau Public Dashboard Link](https://public.tableau.com/app/profile/rudrapratap234/viz/BigBasketPerformance/Dashboard1)

## 3. Data Story & Business Findings
* **Overperforming Categories:** **Household Essentials** (INR 17,060 vs target 17,000) and **Fruits & Vegetables** (INR 12,405 vs target 12,000) cleared their targets successfully.
* **Categories to Watch (Shortfall <= 15%):** **Bakery** achieved INR 11,700 against a 12,000 target (-2.5% variance), and **Dairy & Eggs** achieved INR 18,278 against targets, maintaining steady velocity.
* **Critical Categories:** **Personal Care** missed target significantly (INR 13,286 vs target 15,500, a -14.3% shortfall) due to zero traction on premium SKUs like *Premium Face Cream 50g*.
* **Recommendation:** Reallocate promotional spend and cross-selling campaigns in high-AOV regions (Bengaluru and Mumbai) toward underperforming Personal Care lines.
